About this project

We are researchers focused on sports data analytics. We built this because many "prediction models" lack reproducibility and proper probability calibration. WC Analytics is our attempt to bring rigor to football prediction — open-source, pre-match snapshots, fully reproducible.

Stack: FastAPI · Python · Logistic Regression (L1) · Residual NN · Elo · Poisson (Dixon-Coles) · 43 features · Platt scaling
