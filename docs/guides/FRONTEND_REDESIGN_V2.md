# 前端重构 V2 — 设计文档

## 设计原则

1. **Inter 字体** — 与 Claude 一致的无衬线字体，干净、现代
2. **数据优先** — 表格 > 图表 > 装饰，一行一个决策信号
3. **黑白灰 + 语义色** — 绿色=正边际，红色=负边际，蓝色=重点
4. **大量留白** — 减少视觉密度，提高扫描速度
5. **移动端优先** — 侧栏滑入滑出动画
