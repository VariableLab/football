## 9. 关键反转结论(本次审计最大发现)

### 9.1 项目存在"双叙事"问题

- **README/PRO_OPERATOR_MANUAL 叙事**:v2.0-lr + 59 维 + 55.7% 准确率 + First Principles Research Lab

这两套叙事**互不引用、自相矛盾**。生产站部署的代码版本与文档严重脱节。

### 9.2 V5 路线被隐藏

`PRO_OPERATOR_MANUAL.md:6` 公开了 Telegram Bot Token 前缀 `8815524049:...`——虽然不完整但**违反 Telegram 安全实践**。任何人可借此对机器人进行社工攻击或重放探测。

## 11. 结论

**WC Analytics 在 6-16 仍是一个"活着的、但有显著脱节的中早期项目"**:

- ✅ **生存状态比 5-26 报告好**: 生产站已恢复,数据库成功切到 PG,模块化重构完成
- 🔴 **核心承诺未兑现**: 56.6% 准确率、LR 全量部署、赛前快照锁定、59 维特征——**实测均不符**
- 🟡 **存在双叙事**: README v2.0-lr vs PRO_OPERATOR_MANUAL V5.0 Stacking → 团队可能正在分叉
- 🔴 **用户与商业化无实质进展**: 24 条 feedback 90% 测试数据,0 真实用户

**最大资产**:
- 生产站稳定运行
- 31,521 场比赛 + PostgreSQL 数据底座
- 17 个 LR 权重文件 (含 5 联赛分层 + 1 淘汰赛)
- 模块化代码 + YAML 热配置 + 17 个 APIRouter

**最大风险**:
- 模型版本 0% 部署,准确率宣称不实
- 文档与代码严重脱节,新维护者难以快速进入
- 安全实践薄弱(Telegram Token 暴露)
