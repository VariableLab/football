# 中国足彩（竞彩足球）预测模块技术文档

## 1. 模块概述

`jingcai_predictor.py` 是基于现有世界杯预测引擎扩展的足彩预测模块。它将预测能力从国家队赛事延伸到欧洲五大联赛俱乐部比赛，支持中国体育彩票竞彩足球的 5 种主流玩法预测。

## 2. 核心功能

| 功能 | 说明 |
|------|------|
| CSV 导入 | 从 CSV 批量导入足彩在售比赛 |
| 球队自动识别 | 中文名/英文名/code 自动映射到内置 ELO 数据库 |
| 全玩法预测 | 胜平负、让球、比分、总进球、半全场 |
| 投注策略 | 凯利准则 / 保守 / 概率优先 / EV最大 / 组合策略 |
| 结果持久化 | 预测写入数据库，支持前端展示和历史回测 |

## 3. 数据流

```
CSV 导入 → 球队解析 → 数据库 Match → 预测引擎 → 数据库 Prediction → 报告输出
                ↓
         内置俱乐部 ELO 映射 (95支球队)
```

## 4. 内置俱乐部 ELO 映射

覆盖欧洲五大联赛 95 支主流球队，ELO 基于 ClubElo + 近期表现综合估算（2026年5月）。

| 联赛 | 球队数 | ELO 范围 |
|------|--------|----------|
| 英超 | 20 | 1610–2040 |
| 西甲 | 20 | 1600–2020 |
| 德甲 | 17 | 1640–2010 |
| 意甲 | 20 | 1620–1990 |
| 法甲 | 18 | 1650–1980 |

中文别名映射支持常见叫法（如"皇马"→RMA，"国米"→INT）。

## 5. 预测引擎适配

### 5.1 联赛场景修正

与世界杯中立场不同，联赛预测做了以下适配：

| 修正项 | 世界杯 | 联赛 |
|--------|--------|------|
| 场地类型 | neutral | home |
| 主场优势因子 | 1.0 | 1.15（主队）/ 0.90（客队）|
| 赛事阶段 | group/R16/QF/SF/F | group（联赛统一视为小组赛）|
| 权重策略 | 小组赛 Poisson-heavy，淘汰赛 Elo-heavy | 统一使用 group 权重 |

### 5.2 权重自动切换

引擎通过 `FusionWeight` 表自动按阶段匹配权重：
- 联赛比赛 stage="group" → 使用 `group` 权重（Elo=0.11, Poisson=0.66）
- 若未来扩展杯赛淘汰赛 → 自动切换 `knockout` 权重（Elo=0.45, Poisson=0.31）

## 6. 用法

### 6.1 导入 CSV 并预测

```bash
cd backend
python jingcai_predictor.py import data/jingcai_matches.csv
```

CSV 格式：
```csv
home_team,away_team,handicap,odds_home,odds_draw,odds_away,league,kickoff_at
曼城,狼队,0,1.22,6.50,11.00,英超,2026-05-10 22:00
利物浦,阿森纳,0,2.10,3.40,3.20,英超,2026-05-10 23:30
```

### 6.2 为已有比赛重新预测

```bash
python jingcai_predictor.py predict --league 英超 --date 2026-05-10
```

### 6.3 审计

```bash
python jingcai_predictor.py audit
```

## 7. 输出格式

每场比赛输出：
- **胜平负概率**：主胜/平局/客胜百分比
- **比分 TOP 5**：最可能的具体比分及概率
- **总进球 TOP 5**：0球/1球/2球...概率
- **投注策略**：5种策略的推荐选项、赔率、EV、建议仓位
- **模型拆解**：Elo/Poisson/Players/Market 各子模型原始输出

## 9. 已知限制

1. **俱乐部 ELO 为估算值**：未接入 ClubElo 实时同步，ELO 为 2026年5月手工维护的近似值
2. **无真实球员数据**：PlayerAdjustmentModel 默认战力修正=1.0（无伤病/疲劳信息）
3. **让球未完全适配**：当前让球赔率使用胜平负赔率，未接入真实让球盘数据
4. **中文别名有限**：仅覆盖主流球队，小众球队会创建默认 ELO=1500 的记录
