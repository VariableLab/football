## 一、项目概况

**项目名称**: WC Analytics — 世界杯/竞彩足球数据分析平台
**核心定位**: 基于 Elo + 泊松分布 + 逻辑回归融合 + 残差NN修正的足球比赛概率预测系统
**商业模式**: 免费基础数据 + 卡密付费解锁预测模型
**目标日期**: 2026 年 6 月世界杯开赛前达到生产可用水平

### 🔴 仍存在 (6项，按严重度排序)

**1. 平局预测能力 = 0 — 最大的准确率杀手**
- 平局 Recall: 4.6% (352/7706)，模型几乎不预测平局
- 实际比赛中 25% 是平局，但模型几乎全部预测为主胜或客胜
- 主胜 Recall 偏高 72.3%（模型系统性偏向主胜）
- **修复**: LR 重训时加入 class_weight={'home':1, 'draw':3, 'away':1} 或使用 focal loss

**2. LR 只用了 16% 数据训练 — 严重过拟合**
- 训练: 56.6% (5000样本) vs 生产: 51.3% (30806场) = 差距 5.3%
- 数据库有 30,887 场有赛果比赛，LR 只用了 5000 场
- SERIEA 2023-24 (赔率100%覆盖) 准确率 55.3%，证明全量数据+完整赔率可达 55%+
- **修复**: 全量 30,887 场重训 LR + class_weight 平衡

**3. 6期竞彩开奖未录入 — 策略验证闭环断裂**
- JC20260509~14 状态=drawn 但 draw_result=NULL
- 13期竞彩中只有2期有开奖结果
- **修复**: 从 500.com/zgzcw 半手动爬取并录入

**4. 淘汰赛数据 = 0 — 世界杯必崩**
- stage=knockout: 0 场
- 无世界杯/欧洲杯淘汰赛历史数据
- 数据库中 competition 含 world/cup/euro/champion: **0场**
- **修复**: 导入 openfootball 世界杯历史 + 正确标记淘汰赛

**5. 赔率缺失拖累三大联赛 — 准确率低于随机**
- LaLiga/Bundesliga/Ligue1 缺赔率 47-59%
- 这三联赛准确率 47.8-49.7%，**低于随机 50%**
- EPL/SerieA 赔率较好(64-72%)，准确率也高(52.7-53.4%)
- **修复**: 从 football-data.co.uk 批量下载 CSV 补全

**6. 置信度系统失效 — 高概率推荐全错**
- 99.8% 的预测 confidence=NULL (30973/31044)
- 仅有 low(37) 和 medium(34)，无 high
- 高概率预测 61/61 = 100% 失败
- **修复**: 重新实现 `_compute_confidence()`

### 🟡 新发现的重要问题 (3项)

**7. 联赛命名混乱 — LR 分层前提缺失**
- 同一联赛有5种命名: `EPL` / `EPL 2024-25` / `EPL 2023/24` / `英超` / ...
- Bundesliga: `Bundesliga` / `BUNDESLIGA 2024-25` / `Bundesliga 2023/24` / `德甲`
- LaLiga: `LaLiga` / `LALIGA 2024-25` / `La Liga 2023/24` / `西甲`
- **影响**: LR 联赛分层无法正确分组
- **修复**: 一次性 SQL UPDATE 统一 competition 字段

**8. health_daemon + 自愈闭环完全失效**
- health_daemon 连续 13 次失败
- model_audit/ 目录为空（从未写入审计记录）
- 自愈从未触发过
- 203/203 场赔率全过期，紧急采集触发但未解决
- **修复**: 排查 health_daemon 日志，修复执行链路

**9. 球员数据 99.8% 是 estimated — 比上次评估更差**
- 602 条记录: 601 source=estimated, 1 source=fbref
- 上次评估说"~5%真实率"过于乐观，实际 <1%
- ARCHITECTURE_V2 目标 ≥ 60%，差距巨大
- **修复**: 安装 soccerdata 库，从 FBref 自动采集真实球员统计
