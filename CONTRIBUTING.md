# Contributing to WC Analytics

We welcome contributions! This is an open-source academic research project.

## Ways to Contribute

- **Bug reports & feature requests**: Open a [GitHub Issue](https://github.com/VariableLab/football/issues)
- **Documentation**: Improve README, fix typos, add translations
- **Code**: PRs welcome for prediction models, data pipelines, or UI
- **Research**: Share your own calibration experiments using our data

## Pull Request Process

1. Fork the repo and create a branch from `master`
2. Run existing tests: `pytest tests/`
3. If adding features, include tests
4. Update `docs/` if architecture changes
5. PRs will be reviewed within 7 days

## Code Standards

- Python: type hints, Google-style docstrings, `ruff` linting
- Follow existing patterns in `backend/` rather than introducing new frameworks
- No hardcoded secrets — use environment variables

## Research Ethics

This project is strictly for academic research on probability calibration. No outputs should be interpreted as betting advice.

## Questions?

Open a [Discussion](https://github.com/VariableLab/football/discussions) or check `docs/` for detailed documentation.
